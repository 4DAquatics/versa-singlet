Versa Singlet firmware

Latest version: v3.2

Update over Wi-Fi

For installed units. You need a phone. Nothing has to be unplugged.

  1. First, while your phone still has internet, download the update file:

    Download update file
  2. At the Singlet, press the button 4 times and keep holding the 4th press for about 5 seconds, until the Versa's lights flash and its pump moves. Then let go. The Singlet's light flashes blue.
  3. On your phone, open Wi-Fi settings and join the network Versa-Update-… (no password). If the phone warns there's no internet, choose to stay connected. The Singlet's light now flashes blue faster.
  4. The update page may open by itself. If not, come back to this page and tap:

    Open update page
    Or type the full address into Chrome, including the http:// at the start:
    http://singletupdate  or  http://192.168.4.1
    Without the http:// some browsers search for it or try a secure address the Singlet doesn't have, and say they can't reach this page.
  5. Tap Choose file, pick the file you downloaded, then tap Update. Keep the page open until it says Update installed (about a minute).
  6. The Singlet restarts by itself. Switch your phone back to your normal Wi-Fi. Done.
Flashing blueWi-Fi is on, waiting for your phone
Flashing cyanThe file is arriving: don't switch anything off
GreenUpdate installed, restarting
RedNot updated, nothing was changed. Try again
Wi-Fi switches itself off after 5 minutes if nothing is uploaded. One press of the button switches it off straight away. Your dosing schedule is not affected.
Joined the Wi-Fi but the update page won't open?
  • Use Chrome. Other browsers (Edge, Samsung Internet) may refuse addresses that don't start with https://.
  • Type the address with the http:// at the start, exactly as shown above.
  • Turn off mobile data while you update, so the phone doesn't go around the Singlet's Wi-Fi.
  • Check the phone is still joined to Versa-Update-…. Some phones switch back to another Wi-Fi when there's no internet.

First install over USB-C

For new units at the workbench, before the Singlet is connected to a Versa. You need a computer with Chrome or Edge.

  1. Plug the Singlet into the computer with a USB-C data cable.
  2. Click Install below. A list of ports pops up: pick the one called USB JTAG/serial debug unit and click Connect.
  3. Click Install again in the window that opens, and wait for Installation complete (about 30 seconds).
  4. Unplug. Done.

This browser can't install firmware. Open this page in Chrome or Edge on a computer. This page has to be opened from its https:// address.

No port in the list, or it didn't finish?
  • Try another USB-C cable. Some cables only charge and can't carry data.
  • Close any other program that might be using the port (Arduino IDE, serial monitor), then try again.
  • Unplug the Singlet, plug it back in, and click Install again. Nothing can be damaged by trying again.
